# Qubool Nikah App

A trusted Muslim matrimonial platform focused on meaningful marriage connections.

## Vision

Qubool Nikah App aims to build a privacy-first, verified matrimonial platform that helps Muslims find compatible life partners through trust, transparency, and meaningful connections.

## MVP Goals

- Secure user registration
- Profile creation
- Profile verification
- Match discovery
- Interest system
- Private communication
- Admin moderation

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- Supabase

Hosting:
- Netlify
